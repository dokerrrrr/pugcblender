# Optional Blender skills for PUGC

Open the `SKILL.md` for your task or give the agent its path in your request. This directory is outside the automatic skill discovery paths. Each skill uses existing repository tools and can be used independently.

| Task | Guide |
| --- | --- |
| Match a reference's scale, silhouette, and passages | [Scene assembly](pugc-scene-assembly/SKILL.md) |
| Furnish a street, courtyard, or interior | [Set dressing](pugc-set-dressing/SKILL.md) |
| Review the result and verify corrections | [Visual review](pugc-visual-review/SKILL.md) |
| Record an overview of the finished map | [Camera flythrough](pugc-camera-flyover/SKILL.md) |

If the source scene lacks materials, work from its shape and reference photographs. For a color preview, select an existing face of a catalog asset. Document unknown texture bindings in the report. For video, move the camera. Keep prop motion, painted textures, and water effects out of the game map.
