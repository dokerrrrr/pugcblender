# Set dressing

1. Read the reference for the site's purpose. In a loading yard, for example, place wooden containers along a wall first, keeping the entrance and portico visible from the street. Choose the prop count based on the reference and budget.
2. In the foreground, check the actual front face, texture scale, and support beneath each prop. Review background silhouettes from a wide view. Place props in stable groups while keeping turns and doorways clear.
3. Look for the desired color or wear on existing faces of native models. Rotate the object or choose a different ID. If the catalog lacks a suitable piece, simplify the group. Leave new textures, decals, procedural paint, prop animation, and devices out of this step.
4. Reread the saved `.pugc`. Review the group from eye level and above with native textures, then check the adjacent route. If a crate obstructs the passage, move it in the project and repeat the same test using the same points.
